## Notes

- All documents in this folder are version-controlled alongside the codebase, per the project requirement that any document apart from the Planner board itself be kept in Git.
- Please avoid deleting older versions (e.g. `BA_Requirements.pdf`) unless the team agrees archiving is no longer necessary, they help track the evolution of requirements across the sprint.
- When adding new documents (design files, validation sign-offs, test reports, etc.), please:
    1. Use clear, versioned filenames (e.g. `Design_Validation_v1.pdf`).
    2. Update this README with a short description of the new file.
